# 드레스 옵션 이미지 자산

드레스 선택 화면은 빌드 전에 생성되는 `public/assets/options.svg` SVG symbol sprite를 사용합니다.

- 전체 이미지: 58개
- 실제 디자인 옵션: 57개
- 공통 `기억 안 남` 이미지: 1개
- 카테고리: 어깨/끈 8, 넥라인 8, 실루엣 6, 소재 6, 색상 3, 트레인 4, 허리선 4, 뒤태 6, 디테일 12
- 생성 기준: 목 아래 크롭, 크림 배경, 아이보리 드레스, 로즈 브라운 라인
- 접근성: 이미지 자체는 장식 요소이고 버튼 텍스트가 옵션명을 제공합니다.
- 오프라인: Vite PWA precache에 sprite가 포함됩니다.
- 전송량: 58개 그림을 개별 요청하지 않고 한 번의 SVG sprite 요청으로 불러옵니다.

## 생성 및 검증

- `npm run assets`: 압축된 원본에서 `public/assets/options.svg`를 생성합니다.
- `npm run dev`: 개발 서버 시작 전에 자산을 자동 생성합니다.
- `npm run build`: Vercel 빌드 전에 자산을 다시 생성합니다.
- 단위 테스트: 카테고리별 symbol 연결과 접근성 속성을 검사합니다.
- 모바일 E2E: sprite 응답, 대표 옵션 렌더링, 320px 화면 가로 넘침을 검사합니다.

생성 결과가 Git에 중복 저장되지 않도록 `public/assets/options.svg`는 `.gitignore`에 포함되어 있으며, 동일한 압축 원본으로 항상 같은 자산을 재현합니다.
