# 드레스 옵션 이미지 자산

드레스 선택 화면은 ChatGPT 이미지 생성으로 제작한 웨딩드레스 일러스트를 모바일 선택 카드용으로 재가공한 `public/assets/option-atlas.webp`를 사용합니다.

- 실제 디자인 옵션: 57개
- 공통 `기억 안 남`: 이미지 대신 명시적인 `?` 상태 1개
- 카테고리: 어깨/끈 8, 넥라인 8, 실루엣 6, 소재 6, 색상 3, 트레인 4, 허리선 4, 뒤태 6, 디테일 12
- 비주얼 기준: 얼굴 없는 동일 마네킹, 크림/화이트 배경, 아이보리 계열 웨딩드레스, 옵션 간 차이를 우선한 정면/뒤태 크롭
- 접근성: 이미지 자체는 `aria-hidden` 장식 요소이고 버튼 텍스트가 실제 옵션명을 제공합니다.
- 오프라인: WebP atlas는 PWA precache에 포함됩니다.
- 전송량: 57개 파일을 개별 요청하지 않고 약 36KB의 WebP atlas 한 번만 내려받습니다.

## Atlas 구조

atlas는 8열 × 10행 셀 구조입니다. `OptionArtwork.tsx`가 옵션 ID를 셀 좌표로 매핑하고 CSS background-position으로 해당 이미지만 노출합니다.

1. row 0 — 어깨/끈
2. row 1 — 넥라인
3. row 2 — 실루엣
4. row 3 — 소재
5. row 4 — 색상
6. row 5 — 트레인
7. row 6 — 허리선
8. row 7 — 뒤태
9. row 8~9 — 디테일

원본 이미지는 생성형 이미지 결과에서 카테고리별 동일 구도를 골라 자른 뒤, 모바일 카드 크기에 맞춰 동일한 셀 크기로 패킹했습니다. 생성 결과 자체의 글자는 앱에 사용하지 않고 일러스트 영역만 사용하며, 앱 라벨은 별도의 실제 UI 텍스트로 렌더링합니다.

## 검증

- 단위 테스트: 대표 카테고리가 WebP atlas로 연결되는지, `기억 안 남`이 별도 상태인지, 접근성 속성을 검사합니다.
- 모바일 E2E: 대표 옵션 선택, 320px 화면 가로 넘침, 새로고침 후 선택 유지, 오프라인 재접속을 검사합니다.
- PWA: `/assets/option-atlas.webp`를 precache해 드레스샵 네트워크가 불안정해도 이미 본 앱은 계속 사용할 수 있게 합니다.
- PDF 왕복 테스트: 복원 가능한 PDF의 투어 데이터와 선택적 얼굴 첨부파일을 실제로 다시 읽어 검증합니다.

`public/assets/options.svg`는 이전 E2E/오프라인 경로 호환을 위한 1×1 빈 SVG만 남겨 두었으며 실제 옵션 UI에는 사용하지 않습니다.
