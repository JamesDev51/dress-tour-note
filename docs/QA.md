# Release 1.0 QA checklist

## Functional

- [ ] 새 투어 생성 후 날짜·신부명·메모가 재접속 뒤 유지된다.
- [ ] 샵 추가·수정·순서 변경·삭제·실행 취소가 동작한다.
- [ ] 드레스 추가·복제·순서 변경·삭제·실행 취소가 동작한다.
- [ ] 모든 P0 스타일 enum과 `잘 모르겠음` fallback이 미리보기에 반영된다.
- [ ] 메모 마지막 글자가 route 이동 및 PDF에 포함된다.
- [ ] 후보 2~3벌 비교가 같은 샵·다른 샵 조합에서 모두 동작한다.
- [ ] 얼굴 사진 이동·확대·회전과 두 포함 토글이 재접속 뒤 유지된다.
- [ ] 얼굴 삭제가 Blob과 참조를 함께 제거한다.
- [ ] 원본 PDF 표시 페이지가 일반 PDF 뷰어에서 열린다.
- [ ] 원본 PDF를 빈 기기에서 가져오면 모든 기록이 복원된다.
- [ ] 복사 가져오기와 덮어쓰기가 각각 올바르게 동작한다.
- [ ] 일반·손상·첨부 제거 PDF는 DB 변경 없이 거부된다.
- [ ] 전체 삭제 후 모든 table이 비어 있다.

## Mobile browsers

- [ ] iPhone Safari: PDF 다운로드·파일 선택·뒤로가기·얼굴 조작
- [ ] Android Chrome: 카카오톡 인앱 링크·PDF 다운로드·업로드
- [ ] Samsung Internet: 파일 저장·선택·화면 회전
- [ ] 320px, 360px, 390px, 430px: 가로 overflow 없음

## Privacy

- [ ] DevTools Network에서 앱 asset 외 사용자 데이터 요청이 없다.
- [ ] 첫 화면과 얼굴/PDF 화면의 개인정보 문구가 정확하다.
- [ ] 얼굴 포함 PDF 공유 경고가 표시된다.
- [ ] 원본 PDF만 복원 가능하다는 주의가 표시 페이지와 완료 UI에 있다.
